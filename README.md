# lofiplayer

For all the lofi fans who never want to leave the terminal.


## Requirements

- `python` 3.10+
- `tmux`
- `lowfi` (installed separately, e.g. via Cargo)
- Not supported on Windows

## Installation

Make sure [lowfi](https://github.com/talwat/lowfi) and tmux are already installed first.

```bash
pip install lofiplayer
```


## Usage

```
lofiplayer <youtube video link or local video path>
```
You can feed in entire YouTube playlist as well. It may take a while to load the videos if playlist is large.
If no URL is provided, a default YouTube video is launched.

| Key | Function |
|-----|----------|
| `s` | Skip Song |
| `Space` | Play/Pause audio and video |
| `q`, `CTRL+C` | Quit |
| `n` | next video |
